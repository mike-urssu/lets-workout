## 01. 프로젝트 개요

### 1.1 문서 개요
- 정의하는 것: Let's Workout 서비스의 **운동 기록 기능**이 무엇을 해야 하는지(사용자와 권한, 화면 흐름, 기능, 관리할 데이터, 규칙, 예외, 비기능 요구, 범위).
- 정의하지 않는 것: API 상세 설계, DB 스키마, 아키텍처, 기술 스택(→ 설계 문서에서 다룸). 통계(`workout-stats.md`), 오운완 인증 사진/동영상(`workout-media.md`), 프로필 기능은 별도 문서에서 다룬다.
- 대상 독자: 백엔드 개발자, 모바일 클라이언트 개발자, 테스트 담당자, 기획자.

### 1.2 서비스 / 기능 개요
운동 기록 기능은 사용자가 운동을 시작해서 끝낼 때까지 무엇을 몇 세트, 몇 회, 몇 kg으로 했는지 남기고, 나중에 지난 기록을 다시 볼 수 있게 한다. 기록 단위는 "운동 세션(한 번의 운동) → 세션 안의 운동 → 운동별 세트"이다.

| 기능 영역 | 설명 | 관련 요구사항 |
|----------|------|--------------|
| 운동 세션 진행 | 운동을 시작하고, 끝나면 완료 처리해 기록으로 확정한다. 그만두려면 취소한다. 완료를 잊은 세션은 시스템이 정리한다. | REQ-WORKOUT-001, REQ-WORKOUT-002, REQ-WORKOUT-006, REQ-WORKOUT-010 |
| 세션 내 운동 관리 | 진행 중인 세션에 수행할 운동을 추가하거나 뺀다. | REQ-EXERCISE-001, REQ-EXERCISE-002 |
| 세트 기록 | 운동별로 세트의 중량과 반복 횟수를 기록하고, 고치고, 지운다. 지난번 같은 종목의 세트를 불러와 쓸 수 있다. | REQ-SET-001 ~ REQ-SET-003, REQ-SET-005 |
| 진행 중인 운동 현황 | 운동하는 동안 지금까지 한 종목·세트·볼륨을 홈, 오늘 한 운동, 운동 완료 팝업에서 본다. | REQ-WORKOUT-009 |
| 지난 기록 조회 / 삭제 | 월 달력에서 운동한 날과 부위를 보고, 날짜를 골라 그날 기록을 보고, 필요 없는 기록을 삭제한다. | REQ-WORKOUT-005, REQ-WORKOUT-007, REQ-WORKOUT-008 |

### 1.3 외부 시스템 / 연동
- 부위 이미지와 같은 파일 데이터를 저장하고 조회할 수 있어야 한다. (어디에 저장할지는 설계 단계에서 정한다)
- 사용자가 직접 올리는 오운완 인증 사진/동영상은 `workout-media.md`에서 다룬다.

## 02. 사용자 / 권한

### 2.1 사용자 유형
| 사용자 유형 | 설명 |
|------------|------|
| 비로그인 사용자 | 로그인하지 않은 사용자. 운동 기록 기능을 쓸 수 없다. |
| 일반 사용자 | 로그인한 사용자. 자신의 운동 기록을 만들고, 보고, 고치고, 지운다. |
| 관리자 | 해당 없음 — 관리자 기능은 범위 밖이다(8.1). |
| 시스템 | 사람이 아닌 서비스 자신. 방치된 세션을 정리하는 일만 한다(REQ-WORKOUT-006). |

### 2.2 권한 규칙
| 기능 | 비로그인 | 일반 사용자 |
|------|---------|-----------|
| 운동 목록 조회 | ✕ | ○ (조회만, 운동 추가·수정·삭제 불가) |
| 운동 세션 시작 | ✕ | ○ |
| 세션에 운동 추가 / 삭제 | ✕ | △ 본인 세션 + 진행 중 상태만 |
| 세트 추가 / 수정 / 삭제 | ✕ | △ 본인 세션 + 진행 중 상태만 |
| 운동 세션 완료 | ✕ | △ 본인 세션 + 진행 중 상태만 |
| 이전 기록 불러오기 | ✕ | △ 본인 세션 + 진행 중 상태만, 불러오는 기록도 본인 것만 |
| 운동 달력 / 날짜별 기록 조회 | ✕ | △ 본인 기록만 |
| 운동 기록 삭제 (날짜 단위) | ✕ | △ 본인 기록만 |
| 진행 중인 운동 취소 | ✕ | △ 본인 세션 + 진행 중 상태만 |

- 일반 사용자는 자신의 운동 기록만 조회·수정·삭제할 수 있다. 다른 사용자의 기록은 존재 여부와 관계없이 볼 수 없다. (BR-001)
- 운동·세트를 추가·수정·삭제할 수 있는 것은 진행 중인 세션뿐이다. 완료된 세션은 고칠 수 없고, 잘못 기록했으면 삭제한 뒤 다시 기록한다. (BR-002)
- 완료된 기록은 날짜 단위로 삭제하고(BR-020), 진행 중인 세션은 운동 취소로 지운다(REQ-WORKOUT-010).

## 03. 사용자 시나리오 / 화면 흐름

화면 흐름과 화면 정의는 Figma 디자인을 따른다(8.2).

### 3.1 시나리오: 운동을 시작해서 기록을 남긴다
```
[홈 화면]
        ↓
사용자가 운동 시작을 누른다. 운동 시작 없이 부위와 종목부터 고르면 종목을 고를 때 세션을 자동으로 시작한다. (BR-019)
        ↓
운동 세션 생성 (진행 중)
        ↓
사용자가 부위(가슴, 등, 어깨, 하체 등)를 고른다.
        ↓
[운동 선택 화면] (고른 부위의 종목 목록)
        ↓
사용자가 종목을 고른다. 세션에 없는 종목이면 세션에 추가한다.
        ↓
[운동 기록 화면] (고른 종목 하나)
        ↓
세트 추가 (중량, 반복 횟수 입력) ── 반복
필요하면 이전 기록 불러오기, [오늘 한 운동] 보기
        ↓
다른 종목을 하려면 [운동 선택 화면]이나 [홈 화면]으로 돌아간다.
        ↓
[홈 화면]에서 운동 종료를 누른다. (운동을 그만두려면 운동 취소 → 확인 → 세션과 기록한 세트를 지운다)
        ↓
[운동 완료 팝업] 이번 운동 요약 확인, 오운완 인증 사진·동영상 첨부 (workout-media)
   ├─ 저장하기 → 첨부한 사진·동영상과 함께 세션 완료 → [홈 화면]
   ├─ 건너뛰기 → 사진·동영상 없이 세션 완료 → [홈 화면]
   └─ 팝업 닫기 → 완료하지 않고 운동을 이어간다 → [홈 화면]
```

### 3.2 시나리오: 지난 운동 기록을 본다
```
[운동 기록 화면] (가장 최근에 운동한 날이 있는 달, 그 날이 골라져 있음)
        ↓
사용자가 이전 달 / 다음 달로 이동한다. 달력에는 운동한 날마다 그날 운동한 부위가 표시된다.
        ↓
사용자가 날짜를 고른다.
        ↓
그날의 운동 기록(운동 시간, 총 볼륨, 부위별·종목별 볼륨, 세트, 오운완 인증)을 보여준다.
        ↓
사용자가 오운완 인증 사진·동영상을 누르면 [미디어 뷰어] (workout-media MEDIA-001)
```
- 고른 날짜의 기록을 삭제하면 확인을 거쳐 그날 완료된 세션을 모두 지운다(REQ-WORKOUT-005, BR-020).

#### EX-001 운동 선택
- 진입 조건:
  - 로그인 완료
  - 홈에서 부위를 고름 (진행 중인 세션이 없어도 된다)

  - 종목 선택

  - 부위명
  - 종목 ID, 종목명, 영문 종목명
  - 최근 수행일 (해당 사용자 기준, 오늘로부터 며칠 전인지로 보여준다. 기록이 없으면 "기록 없음")
  - 종목 이미지와 운동 검색은 없다(TODO-018, TODO-017 결정).
- 다음 화면:
  - 운동 기록 화면 (EX-002)
- 관련 요구사항: REQ-EXERCISE-001

#### EX-002 운동 기록
- 진입 조건:
  - 로그인 완료
  - 운동 선택 화면에서 종목을 고름
  - 진행 중인 세션이 있음 (없으면 종목을 고를 때 자동으로 시작한다, BR-019)
- 사용자 행동:
  - 세트 추가
  - 세트의 중량·반복 횟수 입력과 수정
  - 세트 삭제
  - 이 종목을 세션에서 빼기 (REQ-EXERCISE-002)
  - 이전 기록 불러오기, 불러온 값 적용
  - 오늘 한 운동 보기 (EX-003)
  - 운동 선택 화면으로 돌아가기
- 시스템 동작:
  - 진행 중인 세션에서 이 종목에 기록된 세트를 조회한다.
  - 세트 추가·수정·삭제를 저장한다.
  - 새 세트의 중량 입력란에는 직전 세트의 중량을 미리 채운다. 반복 횟수는 비워 둔다.
  - 이 종목의 이전 기록이 있는지 확인하고, 사용자가 원하면 불러온다. (REQ-SET-005)
- 화면 데이터:
  - 종목명, 부위명, 타깃 설명 (예: 가슴 중부 타겟)
  - 기록 중 상태, 경과 시간
  - 세트 번호, 세트 추가 시각, 중량(kg), 반복 횟수
  - 이전 기록이 있는지 여부. 불러왔다면 그 기록의 수행 날짜와 불러온 세트 (아직 적용하지 않은 값으로 구분)
- 다음 화면:
  - 운동 선택 (EX-001)
  - 오늘 한 운동 (EX-003)
- 관련 요구사항: REQ-EXERCISE-001, REQ-EXERCISE-002, REQ-SET-001 ~ REQ-SET-003, REQ-SET-005

#### WO-002 운동 완료 팝업
- 진입 조건:
  - 진행 중인 세션이 있을 때 홈에서 운동 종료를 누름
- 사용자 행동:
  - 이번 운동 요약 확인 (부위를 펼쳐 종목별로 본다)
  - 오운완 인증 사진·동영상 추가 (workout-media)
  - 저장하기
  - 건너뛰기
  - 팝업 닫기
- 시스템 동작:
  - 진행 중인 세션의 요약을 조회한다. (REQ-WORKOUT-009)

### 4.2 기능 상세

#### REQ-WORKOUT-001 운동 세션 시작
- **목적:** 사용자가 한 번의 운동을 시작하고, 이후 운동과 세트를 이 세션에 기록할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
- **사용자 행동:**
  1. 홈 화면에서 운동 시작을 누른다. 또는 진행 중인 세션 없이 운동 선택 화면에서 종목을 고른다. (BR-019)
- **입력:**
  - 없음 (수행 날짜는 시작 시각에서 정해진다)
- **처리 규칙:**
  - 해당 사용자의 운동 세션을 "진행 중" 상태로 만든다.
  - 시작 시각을 기록한다.
  - 수행 날짜는 시작 시각을 사용자가 있는 지역의 날짜로 바꾼 값이다. (BR-004)
  - 해당 사용자에게 이미 진행 중인 세션이 있으면 새 세션을 만들지 않는다. 여러 기기에서 동시에 시작해도 진행 중인 세션은 하나만 생긴다. (BR-011)
- **결과:**
  - 진행 중인 운동 세션이 생성된다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 이미 진행 중인 세션이 있으면 생성하지 않고, 진행 중인 세션이 있다는 것을 알려준다. (ERR-011)
- **관련 화면:** WO-001

#### REQ-EXERCISE-001 세션에 운동 추가
- **목적:** 사용자가 이번 운동에서 수행하는 운동 종목을 세션에 추가할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션이 있어야 한다. 없으면 세션을 자동으로 시작한 뒤 추가한다. (BR-019)
  - 선택한 운동이 서비스가 제공하는 운동 목록에 있어야 한다. (BR-009)
- **사용자 행동:**
  1. 홈에서 부위를 고른다.
  2. 운동 선택 화면에서 종목을 고른다.
- **입력:**
  - 세션 ID
  - 운동 ID
- **처리 규칙:**
  - 선택한 운동을 세션에 추가한다.
  - 세션 안에서 운동의 순서는 추가한 순서대로 유지한다.
  - 이미 세션에 있는 종목을 고르면 다시 추가하지 않고, 그 종목의 운동 기록 화면으로 간다.
  - 진행 중인 세션이 없으면 REQ-WORKOUT-001과 같은 규칙으로 세션을 시작한 뒤 종목을 추가한다. (BR-019)
- **결과:**
  - 세션에 운동이 추가되고, 세트가 없는 상태로 운동 기록 화면에 나타난다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 존재하지 않는 운동이면 추가할 수 없다. (ERR-002)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 완료된 세션이면 추가할 수 없다. (ERR-007)
- **관련 화면:** EX-001, EX-002

#### REQ-EXERCISE-002 세션에서 운동 삭제
- **목적:** 사용자가 잘못 추가한 운동을 세션에서 뺄 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션에 해당 운동이 있어야 한다.
- **사용자 행동:**
  1. 운동 기록 화면에서 운동 삭제를 누른다.
- **입력:**
  - 세션 ID
  - 세션 내 운동 ID
- **처리 규칙:**
  - 세션에서 운동을 삭제한다.
  - 그 운동에 기록된 세트도 함께 삭제한다. (NFR-INTEG-002)
- **결과:**
  - 세션에서 운동과 그 세트가 사라진다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 완료된 세션이면 삭제할 수 없다. (ERR-007)
  - 해당 운동이 세션에 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
- **관련 화면:** EX-002

#### REQ-SET-001 세트 기록 추가
- **목적:** 사용자가 운동마다 수행한 세트를 기록할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션에 해당 운동이 있어야 한다.
- **사용자 행동:**
  1. 운동 기록 화면에서 세트 추가를 누른다.
  2. 중량과 반복 횟수를 입력한다.
- **입력:**
  - 세션 내 운동 ID
  - 중량
  - 반복 횟수
- **처리 규칙:**
  - 해당 운동의 마지막 세트 다음 번호로 세트를 저장한다.
  - 세트를 추가한 시각을 기록한다. (REQ-WORKOUT-006에서 종료 시각으로 쓴다)
  - 반복 횟수는 1 이상 1,000 이하의 정수여야 한다. (BR-003)
  - 중량은 kg 단위, 0 이상 1,000 이하, 소수점 둘째 자리까지여야 한다. (BR-005)
- **결과:**
  - 세트가 생성된다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 입력값이 규칙에 맞지 않으면 저장하지 않는다. (ERR-005)
  - 완료된 세션이면 추가할 수 없다. (ERR-007)
  - 해당 운동이 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
  - 필수 입력이 빠졌으면 저장하지 않는다. (ERR-010)
- **관련 화면:** EX-002

#### REQ-SET-002 세트 기록 수정

- **입력:**

  - 중량

- **결과:**

- **예외:**

  - 다른 사용자의 세트이면 권한 오류를 반환한다. (ERR-003)

  - 완료된 세션이면 수정할 수 없다. (ERR-007)

#### REQ-SET-005 이전 기록 불러오기
- **목적:** 사용자가 지난번 같은 종목에서 한 중량·반복 횟수를 다시 입력하지 않고 가져와 이번 세트로 쓸 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션에 해당 종목이 있어야 한다.
  - 이 종목을 기록한 완료된 세션이 있어야 한다. 없으면 불러올 수 없다. (ERR-013)
- **사용자 행동:**
  1. 운동 기록 화면에서 이전 기록 불러오기를 누른다.
  2. 이 종목에 이미 기록한 세트가 있으면 바꿀지 확인한다.
  3. 불러온 값을 눌러 이번 세트로 적용하거나, 고친 뒤 적용한다.
- **입력:**
  - 세션 내 운동 ID
- **처리 규칙:**
  - 본인의 기록에서만 가져온다. (BR-001)
  - 이 종목을 기록한 가장 최근의 완료된 세션에서 세트를 세트 번호 순으로 가져온다. (BR-016)
  - 가져온 기록의 수행 날짜를 함께 알려준다.
  - 불러온 값은 사용자가 적용하기 전에는 세트로 기록되지 않는다. (BR-017)
  - 적용한 값은 적용한 시각에 세트를 추가한 것으로 기록한다. REQ-SET-001과 같은 규칙(BR-003, BR-005)을 적용한다.
  - 이 종목에 이미 기록한 세트와 아직 적용하지 않은 불러온 값을 모두 지우고 불러온 값으로 바꾼다. 기록한 세트가 있으면 사용자가 확인한 뒤에만 바꾼다. (BR-021)
  - 여러 번 다시 불러올 수 있다. (BR-021)
- **결과:**
  - 이전 기록의 세트 값과 수행 날짜를 받는다.
  - 적용한 값은 이번 세션의 세트로 생성된다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 완료된 세션이면 적용할 수 없다. (ERR-007)
  - 해당 운동이 세션에 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
  - 불러올 이전 기록이 없으면 이전 기록이 없다고 알린다. (ERR-013)
- **관련 화면:** EX-002

#### REQ-WORKOUT-002 운동 세션 완료
- **목적:** 사용자가 운동을 끝내고 이번 운동을 기록으로 확정할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션이 있어야 한다.
  - 세션에 기록한 세트가 하나 이상 있어야 한다. (BR-012)
- **사용자 행동:**
  1. 홈에서 운동 종료를 누른다.
  2. 운동 완료 팝업에서 이번 운동 요약을 확인한다.
  3. 필요하면 오운완 인증 사진·동영상을 추가한다. (workout-media REQ-MEDIA-001)
  4. 저장하기 또는 건너뛰기를 누른다.
- **입력:**
  - 세션 ID
  - 오운완 인증 사진·동영상 (선택, 저장하기일 때만. workout-media)
- **처리 규칙:**
  - 저장하기나 건너뛰기를 누른 시각을 종료 시각으로 기록한다. 종료 시각은 시작 시각보다 앞설 수 없다. (BR-008)
  - 세션 상태를 "완료"로 바꾼다. 이후에는 수정할 수 없다. (BR-002)
  - 건너뛰기는 사진·동영상 없이 완료한다.
  - 운동 완료 팝업을 닫으면 완료하지 않는다. 세션은 진행 중인 채로 남는다.
  - 세션 요약(운동 시간, 운동 수, 총 세트 수, 총 반복 횟수, 총 무게)과 부위별·종목별 요약을 확인할 수 있게 한다. (BR-010, BR-015)
  - 세트가 하나도 없으면 완료하지 않는다. (BR-012)
  - 세트가 없는 운동은 지우지 않고 그대로 둔다. 운동 수에는 들어가지 않는다. (BR-010)
  - 불러왔지만 적용하지 않은 값은 기록에 남지 않는다. (BR-017)
  - 저장하기에서 사진·동영상 업로드에 실패하면 완료하지 않는다. (workout-media BR-007)
- **결과:**
  - 세션이 완료되고 운동 기록 달력에 나타난다.
  - 홈 화면으로 돌아간다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 이미 완료된 세션이면 다시 완료할 수 없다. (ERR-008)
  - 세션이 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
  - 세트가 없으면 완료하지 않고, 세트를 기록하거나 운동을 취소하라고 알려준다. (ERR-012, REQ-WORKOUT-010)
- **관련 화면:** WO-001, WO-002

#### REQ-WORKOUT-005 운동 기록 삭제
- **목적:** 사용자가 잘못 만들었거나 필요 없는 운동 기록을 지울 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 고른 날짜에 본인의 완료된 운동 기록이 있어야 한다.
- **사용자 행동:**
  1. 운동 기록 화면에서 날짜를 고르고 삭제를 누른다.
  2. 삭제를 확인한다.
- **입력:**
  - 날짜
- **처리 규칙:**
  - 그날 본인의 완료된 세션을 모두 삭제한다. 날짜별 기록은 그날 세션을 합쳐 보여주기 때문이다. (BR-020)
  - 세션 안의 운동, 세트, 오운완 인증 사진·동영상을 함께 삭제한다. (NFR-INTEG-002, workout-media BR-004)
  - 진행 중인 세션은 여기서 지우지 않는다. 운동 취소(REQ-WORKOUT-010)로 지운다.
  - 삭제한 기록은 보관하지 않고 완전히 지운다. 삭제 후에는 되돌릴 수 없다. (TODO-001 결정)
- **결과:**
  - 그날의 기록이 달력과 날짜별 기록에서 사라진다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 그날 기록이 없거나 이미 삭제되었으면 찾을 수 없음 오류를 반환한다. (ERR-004)
  - 날짜 형식이 잘못되었으면 입력값 오류를 반환한다. (ERR-015)
- **관련 화면:** WO-003

#### REQ-WORKOUT-006 방치된 세션 자동 완료
- **목적:** 사용자가 완료를 잊은 세션이 운동 시간을 왜곡하거나 새 운동 시작을 계속 막지 않도록, 시스템이 정리할 수 있어야 한다.
- **사전 조건:**
  - 시작한 지 6시간이 지났는데 아직 진행 중인 세션이 있다. (BR-013)
- **사용자 행동:**
  - 없음 (시스템이 수행한다)
- **입력:**
  - 없음
- **처리 규칙:**
  - 기록한 세트가 하나 이상 있으면 세션을 "완료"로 바꾼다. 종료 시각은 남아 있는 세트 중 가장 늦게 추가된 세트의 추가 시각으로 한다. (BR-013)
  - 기록한 세트가 하나도 없으면 세션을 삭제한다. 삭제 방식은 REQ-WORKOUT-005와 같다. (BR-013, BR-012)
  - 사용자가 직접 완료할 때(REQ-WORKOUT-002)와 같이 완료 후에는 수정할 수 없다. (BR-002)
  - 시작한 지 6시간이 지난 세션 때문에 새 세션 시작이 막히지 않아야 한다. (BR-011)
- **결과:**
  - 방치된 세션이 완료되거나 삭제된다.
  - 사용자는 홈에서 새 운동을 시작할 수 있고, 완료된 세션은 운동 기록 목록에 나타난다.
- **예외:**
  - 처리 중 오류가 나도 일부만 완료되거나 일부만 삭제된 세션이 남지 않는다. (NFR-AVAIL-001)
  - 사용자가 자동 완료된 세션을 고치려 하면 완료된 기록이라 수정할 수 없다는 오류를 반환한다. (ERR-007)
  - 사용자가 자동 삭제된 세션을 요청하면 찾을 수 없음 오류를 반환한다. (ERR-009)
- **관련 화면:** WO-001, WO-003 (처리 결과가 나타나는 화면)

#### REQ-WORKOUT-007 월별 운동 달력 조회
- **목적:** 사용자가 한 달 동안 언제 어떤 부위를 운동했는지 한눈에 볼 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
- **사용자 행동:**
  1. 운동 기록 화면에 들어온다.
  2. 이전 달 / 다음 달로 이동한다.
- **입력:**
  - 연·월
- **처리 규칙:**
  - 본인의 운동 기록만 조회한다. (BR-001)
  - 그 달에 운동한 날마다 그날 세트를 기록한 부위를 알려준다. (BR-018)
  - 완료된 세션만 포함한다. 진행 중인 세션은 보여주지 않는다. (BR-018)
- **결과:**
  - 그 달의 운동한 날짜와 날짜별 부위 목록을 받는다.
  - 그 달에 운동한 날이 없으면 빈 결과를 받는다(오류가 아니다).
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 연·월 형식이 잘못되었으면 입력값 오류를 반환한다. (ERR-014)
- **관련 화면:** WO-003

#### REQ-WORKOUT-008 날짜별 운동 기록 조회
- **목적:** 사용자가 고른 날에 무엇을 얼마나 했는지 세트 단위까지 다시 볼 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
- **사용자 행동:**
  1. 운동 기록 화면의 달력에서 날짜를 고른다.
- **입력:**
  - 날짜
- **처리 규칙:**
  - 본인의 운동 기록만 조회한다. (BR-001)
  - 그날의 운동 시간, 총 볼륨, 부위별 볼륨·세트 수, 종목별 볼륨·세트 수, 종목별 세트 목록(세트 번호 순 중량·반복 횟수)을 제공한다. (BR-010, BR-015)
  - 완료된 세션만 포함한다. 진행 중인 세션은 보여주지 않는다. (BR-018)
  - 그날의 오운완 인증 사진·동영상 목록을 함께 제공한다. (workout-media REQ-MEDIA-002)
  - 하루에 완료된 세션이 여러 개면 하나로 합쳐 보여준다. 운동 시간은 세션마다의 운동 시간을 더한 값이다. (BR-020)
- **결과:**
  - 그날의 운동 기록을 받는다.
  - 운동하지 않은 날이면 빈 결과를 받는다(오류가 아니다).
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 날짜 형식이 잘못되었으면 입력값 오류를 반환한다. (ERR-015)
- **관련 화면:** WO-003

#### REQ-WORKOUT-009 진행 중인 세션 현황 조회
- **목적:** 사용자가 운동하는 동안 지금까지 무엇을 얼마나 했는지 홈, 오늘 한 운동, 운동 완료 팝업에서 볼 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
- **사용자 행동:**
  1. 홈 화면을 본다. 또는 오늘 한 운동 보기를 누른다. 또는 운동 종료를 누른다.
- **입력:**
  - 없음 (요청한 사용자 본인)
- **처리 규칙:**
  - 본인의 진행 중인 세션만 조회한다. 진행 중인 세션은 많아야 하나다. (BR-001, BR-011)
  - 시작 시각(경과 시간을 보여주기 위해), 세트가 있는 종목 목록(세션에 추가한 순서)과 종목별 부위·첫 세트의 추가 시각·세트 수·볼륨, 부위별 볼륨·세트 수, 합계(종목 수, 총 세트 수, 총 볼륨)를 제공한다. (BR-010, BR-015)
  - 불러왔지만 적용하지 않은 값은 넣지 않는다. (BR-017)
- **결과:**
  - 진행 중인 세션의 현황을 받는다.
  - 진행 중인 세션이 없으면 없다는 결과를 받는다(오류가 아니다).
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
- **관련 화면:** WO-001, EX-003, WO-002

#### REQ-WORKOUT-010 진행 중인 운동 취소
- **목적:** 사용자가 기록할 생각이 없어진 운동을 기록으로 남기지 않고 그만둘 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션이 있어야 한다.
- **사용자 행동:**
  1. 홈 화면의 진행 중인 운동에서 운동 취소를 누른다.
  2. 취소를 확인한다.
- **입력:**
  - 세션 ID
- **처리 규칙:**
  - 진행 중인 세션과 그 안의 운동, 세트를 함께 완전히 삭제한다. (NFR-INTEG-002)
  - 세트가 없어 완료할 수 없는 세션(BR-012)도 이것으로 지운다.
- **결과:**
  - 진행 중인 세션이 사라지고, 홈에서 새로 운동을 시작할 수 있다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 이미 완료된 세션이면 취소하지 않고 오류를 반환한다. (ERR-008)
  - 진행 중인 세션이 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
- **관련 화면:** WO-001

## 05. 데이터 요구사항

#### DATA-001 운동 세션(운동 기록)
- 설명: 사용자가 한 번 운동한 단위. "운동 기록"이라고도 부른다.
- 관리해야 하는 정보: 기록한 사용자, 수행 날짜, 시작 시각, 종료 시각, 상태(진행 중 / 완료)
- 관계: 한 명의 사용자에 속한다. 0개 이상의 세션 내 운동을 가진다. 0개 이상의 오운완 인증 사진·동영상을 가진다(workout-media DATA-001).
- 생명주기: 운동 시작 시 "진행 중"으로 생성 → 사용자가 완료하거나, 6시간이 지나 자동으로 완료·삭제(BR-013) → 완료되면 이후 수정 불가 → 사용자 요청 시 완전히 삭제(보관하지 않음, TODO-001 결정). 운영자가 계정을 삭제하면 그 사용자의 운동 기록도 모두 함께 삭제(auth BR-012)
- 관련 규칙: BR-001, BR-002, BR-004, BR-008

#### DATA-002 운동(종목)
- 설명: 벤치프레스, 스쿼트처럼 사용자가 수행하는 운동의 종류
- 관리해야 하는 정보: 운동명, 영문 운동명, 카테고리(부위, DATA-006), 타깃 설명(예: 가슴 중부 타겟), 카테고리 안에서의 순서 (종목 이미지는 두지 않는다, TODO-018)
- 관계: 하나의 카테고리에 속한다. 여러 세션 내 운동에서 참조된다.
- 생명주기: 서비스가 미리 제공한다. 사용자는 운동을 만들거나 고치거나 지울 수 없다. 초기 목록은 부록 A를 따른다(TODO-014).
- 관련 규칙: BR-009

#### DATA-003 세션 내 운동
- 설명: 특정 세션에서 수행한 운동 하나
- 관리해야 하는 정보: 소속 세션, 운동(종목), 세션 안에서의 순서
- 관계: 하나의 세션에 속한다. 하나의 운동(종목)을 가리킨다. 0개 이상의 세트를 가진다.
- 생명주기: 진행 중인 세션에 추가 시 생성 → 진행 중에만 삭제 가능 → 세션이 삭제되면 함께 삭제
- 관련 규칙: BR-002

#### DATA-004 세트
- 설명: 세션 내 운동에서 수행한 한 세트
- 관리해야 하는 정보: 세트 번호, 중량(kg), 반복 횟수, 추가한 시각
- 관계: 하나의 세션 내 운동에 속한다.
- 생명주기: 진행 중인 세션에서 추가·수정·삭제 → 세션 완료 후 수정 불가 → 상위 운동이나 세션이 삭제되면 함께 삭제
- 관련 규칙: BR-002, BR-003, BR-005, BR-007

#### DATA-005 세션 요약
- 설명: 세션의 운동 결과를 한눈에 보여주는 값. 저장할지 매번 계산할지는 설계에서 정한다.
- 관리해야 하는 정보: 운동 시간(종료 시각 − 시작 시각, 중간에 쉰 시간 포함), 운동 수, 총 세트 수, 총 반복 횟수, 총 무게(총 볼륨), 부위별 볼륨·세트 수, 종목별 볼륨·세트 수 (소모 칼로리는 다루지 않는다)
- 관계: 하나의 세션에 대응한다. 날짜별 기록(REQ-WORKOUT-008)은 그날 세션들의 요약으로 만든다.
- 생명주기: 세션 내용에서 산출된다.
- 관련 규칙: BR-008, BR-010, BR-015

#### DATA-006 운동 카테고리(부위)
- 설명: 가슴, 등, 어깨, 하체처럼 종목을 묶는 부위
- 관리해야 하는 정보: 부위명, 부위 이미지, 순서
- 관계: 여러 종목(DATA-002)을 가진다.
- 생명주기: 서비스가 미리 제공한다. 사용자는 만들거나 고칠 수 없다. 가슴, 등, 어깨, 하체 4개다(TODO-014).
- 관련 규칙: BR-009, BR-015, BR-018

## 06. 비즈니스 규칙 / 예외

### 6.1 비즈니스 규칙
- **BR-001** 사용자는 자신의 운동 기록만 조회·수정·삭제할 수 있다.
- **BR-002** 완료된 운동 세션에는 운동·세트를 추가·수정·삭제할 수 없다. 종료 시각 등 세션 정보도 고칠 수 없다.
- **BR-003** 세트의 반복 횟수는 1 이상 1,000 이하의 정수여야 한다.
- **BR-004** 운동 세션의 수행 날짜는 시작 시각을 사용자가 있는 지역의 날짜로 바꾼 값이다. 사용자가 직접 정할 수 없으므로 미래 날짜는 생기지 않는다.
- **BR-005** 세트의 중량은 kg 단위로 기록하며 0 이상 1,000 이하, 소수점 둘째 자리까지 허용한다. (맨몸 운동은 0)
- **BR-006** ~~세트의 휴식 시간은 초 단위로 기록하며 0 이상 3,600 이하의 정수여야 한다.~~ **폐기 (2026-10-05)** — 휴식 시간을 기록하지 않는다.
- **BR-007** 한 운동 안의 세트 번호는 1부터 빈 번호 없이 이어진다.
- **BR-008** 세션의 종료 시각은 시작 시각보다 앞설 수 없다.
- **BR-009** 세션에는 서비스가 제공하는 운동 목록에 있는 운동만 추가할 수 있다. 사용자는 운동 종목을 만들거나 고칠 수 없다.
- **BR-010** 세션 요약은 기록된 모든 세트로 계산한다. 총 무게는 세트마다 "중량 × 반복 횟수"를 구해 모두 더한 값이다. 운동 수는 세트가 하나 이상 있는 운동만 센다.
- **BR-011** 한 사용자의 진행 중인 세션은 동시에 하나만 있을 수 있다.
- **BR-012** 기록한 세트가 하나 이상 있어야 세션을 완료할 수 있다.
- **BR-013** 시작한 지 6시간이 지나도 진행 중인 세션은 시스템이 정리한다. 세트가 있으면 가장 늦게 추가된 세트의 추가 시각을 종료 시각으로 하여 완료하고, 없으면 삭제한다.
- **BR-014** ~~운동 이미지는 선택 사항이다. 이미지가 없거나 불러오지 못한 운동은 기본 이미지로 보여준다.~~ **폐기 (2026-10-09)** — 종목 이미지를 두지 않는다(TODO-018).
- **BR-015** 부위별 볼륨은 그 부위에 속한 종목의 세트마다 "중량 × 반복 횟수"를 구해 모두 더한 값이고, 부위별 세트 수는 그 부위 종목의 세트 수 합이다. 종목별 볼륨·세트 수도 같은 방식으로 계산한다. 계산에 쓰는 세트는 BR-010과 같다.
- **BR-016** 이전 기록 불러오기는 그 종목을 기록한 가장 최근의 완료된 세션에서 세트를 가져온다. 진행 중인 세션은 대상이 아니다.
- **BR-017** 불러온 값은 사용자가 적용하기 전에는 세트가 아니다. 세션 요약, 완료 조건(BR-012), 통계에 들어가지 않고, 세션을 완료할 때 적용하지 않은 값은 남지 않는다.
- **BR-018** 운동 달력에는 운동한 날마다 그날 세트를 기록한 부위를 표시한다. 날짜는 세션의 수행 날짜(BR-004)를 따른다. 달력과 날짜별 기록에는 완료된 세션만 나온다.
- **BR-019** 진행 중인 세션 없이 종목을 고르면 세션을 자동으로 시작하고 그 종목을 추가한다. 진행 중인 세션은 하나뿐이라는 규칙(BR-011)은 그대로 적용된다.
- **BR-020** 하루에 완료된 세션이 여러 개면 날짜별 기록에서 하나로 합쳐 보여준다(운동 시간은 더한다). 기록 삭제도 날짜 단위로, 그날 완료된 세션을 모두 지운다.
- **BR-021** 이전 기록을 불러오면 그 종목에 기록한 세트와 적용하지 않은 불러온 값을 모두 지우고 불러온 값으로 바꾼다. 기록한 세트가 있으면 먼저 사용자의 확인을 받는다. 여러 번 다시 불러올 수 있다.
